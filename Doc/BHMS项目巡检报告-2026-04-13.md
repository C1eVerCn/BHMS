## 4. 本次修复与运行侧重点

### 4.1 已确认修复

1. **Neo4j GraphRAG 真实检索问题**
   - 修复 `SeedKnowledge.get_fault_details()` 错误读取问题
   - 修复后 Neo4j 后端可正常参与机理解释

2. **前端 API 路由与开发代理问题**
   - 移除 `/api/v2` 的硬编码
   - 将 Vite 代理目标改为可配置
   - 支持通过 `VITE_DEV_PROXY_TARGET` / `BHMS_DEV_PROXY_TARGET` 驱动前端联调

3. **后端启动过慢问题**
   - `backend/app/services/battery_service.py` 改为按需加载数据适配器与训练模块
   - `ml/training/__init__.py` 改为懒加载导出，避免启动时把整套训练栈一并导入

### 4.2 当前推荐运行方式

后端建议：

```bash
BHMS_GRAPH_BACKEND=neo4j \
BHMS_NEO4J_URI=bolt://127.0.0.1:7687 \
BHMS_NEO4J_USER=neo4j \
BHMS_NEO4J_PASSWORD=bhmsneo4j \
BHMS_NEO4J_DATABASE=neo4j \
BHMS_DB_PATH=/tmp/bhms-neo4j-runtime.db \
./.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8001
```

前端建议：

```bash
cd frontend
VITE_DEV_PROXY_TARGET=http://127.0.0.1:8001 node ./node_modules/vite/bin/vite.js --host 127.0.0.1 --port 3005
```
